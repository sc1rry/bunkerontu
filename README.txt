БУНКЕР: ЕКОНОМІКА
==================
Готовий статичний сайт для карткової гри.

ЯК ЗАПУСТИТИ
- Найпростіше: відкрийте файл bunker_economy.html у Chrome, Firefox чи Edge.
- Для хостингу: завантажте index.html, data.js, app.js та styles.css в одну папку
  на GitHub Pages, Netlify або будь-який статичний хостинг.
- Інтернет і сервер для гри на одному пристрої не потрібні.

МОЖЛИВОСТІ
- 176 карт з 8 категорій (усі з вашого тексту, виправлені дві очевидні описки).
- 1–8 карт кожному; за замовчуванням 8, по одній з кожної категорії.
- До 8 команд і 80 гравців загалом.
- Приватний перегляд власних карт, публічне відкриття карт по одній.
- Раунди, виключення, повернення і підсумки.
- Історія роздач за категоріями зберігається через localStorage.
- Коли в категорії закінчилися картки, колода перемішується знову,
  а нещодавно використані картки відсуваються на кінець черги.
- Якщо більше 20 гравців з усіма 8 категоріями, дублікати в окремих
  категоріях математично неминучі (там лише 20 карт).

ВАЖЛИВО
- Це локальна гра на одному пристрої: немає загальних кімнат між телефонами.
- Зміни карт особливого випадку виконуються за правилами вручну; автоматичного
  переносу чужого багажу або обміну між персонажами ця версія не робить.
- Очищення даних браузера/використання іншого браузера скине збережений прогрес.
